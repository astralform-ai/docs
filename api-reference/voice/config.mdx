title: "Voice Config"
description: "What a client needs to run the microphone for an agent: modes, defaults and vocabulary — never the provider."
api: "GET /v1/voice/config"
---

## Endpoint

```
GET https://api.astralform.ai/v1/voice/config
```

Accepts an API key or an end-user OAuth token (send `X-Agent-ID` with a user token).

## Response

```json
{
  "enabled": true,
  "modes": ["raw", "light", "structured", "formal"],
  "default_mode": "structured",
  "silence_auto_stop_seconds": 2.0,
  "auto_send": true,
  "max_recording_seconds": 300,
  "supports_streaming": false,
  "hotwords": ["Astralform", "Capsule"]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `enabled` | boolean | The developer enabled voice input for this agent. Mirrors the `voice` capability on `/v1/agent/status`. |
| `modes` | string[] | The styles a client may request. `raw` never calls the polish model. |
| `default_mode` | string | The style to use when the user has not picked one. |
| `silence_auto_stop_seconds` | number | In tap-to-talk mode, the pause that ends a recording. |
| `auto_send` | boolean | Whether the client should send the message as soon as the result is ready. |
| `max_recording_seconds` | integer | Longest recording to accept before stopping. |
| `supports_streaming` | boolean | Whether the configured recognizer emits live partial transcripts. Batch (Whisper-style) providers do not. |
| `hotwords` | string[] | The project vocabulary. Send it back — plus the user's own words — with each request. |

<Note>
The response deliberately carries no provider or model names. An end-user token must not learn which vendor the developer configured.
</Note>
