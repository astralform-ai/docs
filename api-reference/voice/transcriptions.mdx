---
title: "Transcribe a Recording"
description: "Turn one recording into text with the agent's configured speech-to-text provider."
api: "POST /v1/voice/transcriptions"
---

## Endpoint

```
POST https://api.astralform.ai/v1/voice/transcriptions
```

Accepts an API key or an end-user OAuth token with `X-Agent-ID`; both forms are shown on [Voice Config](/api-reference/voice/config).

## Request

`multipart/form-data`:

| Part | Type | Required | Description |
|------|------|----------|-------------|
| `file` | file | Yes | The recording. 16 kHz mono 16-bit WAV is the reference format; anything the provider accepts works. |
| `hotwords` | string | No | The user's own vocabulary, comma-separated — not the project's, which the server already holds. A word cannot itself contain a comma. |
| `language` | string | No | ISO 639-1 hint (`en`, `zh`). Omit for auto-detection. |

The server merges the project vocabulary with these words, project words first, and sends the result to the provider as its biasing prompt within a 240-character budget.

```bash
curl -X POST https://api.astralform.ai/v1/voice/transcriptions \
  -H "Authorization: Bearer sk_xxxxxxxxxxxx" \
  -F "file=@clip.wav;type=audio/wav" \
  -F "hotwords=MCP, LangGraph"
```

## Response

```json
{
  "text": "let's ship the voice feature on friday",
  "language": "en",
  "duration_ms": 4120,
  "asr_ms": 610
}
```

| Field | Type | Description |
|-------|------|-------------|
| `text` | string | The transcript as the provider produced it. |
| `language` | string \| null | The language the provider detected. |
| `duration_ms` | integer \| null | Length of the recording, when the WAV header says so. |
| `asr_ms` | integer | Time the provider took. |

## Errors

| Status | `error` | Meaning |
|--------|---------|---------|
| 400 | — | Empty recording, larger than the most generous configured channel accepts (25 MB for the hosted providers), or refused by the provider as unusable audio. |
| 409 | `voice_not_ready` | Voice input is disabled, or no speech-to-text channel has a usable key. |
| 429 | — | The project's own `voice.transcribe` rate limit. A provider's 429 never reaches the caller: that channel goes on cooldown and the next configured channel takes the recording. |
| 502 | `transcription_failed` | Every configured channel failed to return a transcript. Details are logged server-side; the response names no vendor, and which channel answered a successful request is never reported either. |
