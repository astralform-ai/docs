---
title: "List Agents"
api: "GET /v1/agents"
description: "Get available agents for the project."
---

Returns the agents configured for this project. Use the `name` of one as `agent_name` when [creating a job](/api-reference/chat/stream) to route a message to it.

## Authentication

<ParamField header="Authorization" type="string" required>
  Your project API key as a bearer token: `Bearer sk_xxxxxxxxxxxx`
</ParamField>

## Response

<ResponseField name="agents" type="array">
  Array of agent objects
  <Expandable title="Agent object">
    <ResponseField name="id" type="string" required>
      The agent's id
    </ResponseField>
    <ResponseField name="name" type="string" required>
      Agent identifier (lowercase with hyphens) — this is what `agent_name` takes
    </ResponseField>
    <ResponseField name="display_name" type="string | null" required>
      Human-readable name, or `null`
    </ResponseField>
    <ResponseField name="avatar_url" type="string | null">
      The agent's avatar, or `null`
    </ResponseField>
    <ResponseField name="code_projects_enabled" type="boolean">
      Whether this agent's tasks can name a repository — derived from an enabled `github` connector whose workspace holds an installation. Clients read it to decide whether to offer Projects and Tasks.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET https://api.astralform.ai/v1/agents \
  -H "Authorization: Bearer sk_xxxxxxxxxxxx"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "id": "3f9a1c72-5b84-4e10-a6d3-0c17e2b95f48",
    "name": "support-agent",
    "display_name": "Customer Support",
    "avatar_url": null,
    "code_projects_enabled": false
  }
]
```

```json 401
{
  "detail": "Invalid or missing API key"
}
```
</ResponseExample>

## Usage Notes

<Note>
  The response carries **one entry today** — the project's own agent row. Multi-agent discovery through this endpoint is not implemented; a client that needs to offer a choice cannot build it from here yet.
</Note>

- There is no enabled filter on this route — every configured agent is returned
- Use `agent_name` in [Stream a Chat](/api-reference/chat/stream) to route to a specific agent
- If no `agent_name` is provided, the default agent (or supervisor) handles the request
