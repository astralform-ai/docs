---
title: "List Agents"
api: "GET /v1/agents"
description: "Get available agents for the project."
---

Returns enabled agents configured for this project. SDKs use this to discover available agents and route messages to specific ones.

## Authentication

<ParamField header="Authorization" type="string" required>
  Your project API key as a bearer token: `Bearer sk_xxxxxxxxxxxx`
</ParamField>

## Response

<ResponseField name="agents" type="array">
  Array of agent objects
  <Expandable title="Agent object">
    <ResponseField name="name" type="string">
      Agent identifier (lowercase with hyphens)
    </ResponseField>
    <ResponseField name="display_name" type="string">
      Human-readable name (optional)
    </ResponseField>
    <ResponseField name="description" type="string">
      What this agent specializes in (optional)
    </ResponseField>
    <ResponseField name="is_default" type="boolean">
      Whether this is the project's default agent
    </ResponseField>
    <ResponseField name="is_enabled" type="boolean">
      Whether the agent is currently enabled
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET https://api.astralform.ai/v1/agents \
  -H "Authorization: Bearer sk_xxxxxxxxxxxx"
```
</RequestExample>

<ResponseExample>
```json 200
[
  {
    "name": "support-agent",
    "display_name": "Customer Support",
    "description": "Handles customer inquiries, refunds, and account issues.",
    "is_default": true,
    "is_enabled": true
  },
  {
    "name": "code-reviewer",

```

```json 401
{
  "detail": "Invalid or missing API key"
}
```
</ResponseExample>

## Usage Notes

<Note>
  Call this endpoint directly rather than reading `session.agents` from the iOS SDK: its `AgentInfo` type cannot decode what this endpoint returns, and `ChatSession.fetchAgents` swallows the failure, so the collection is always empty.

  The response fields documented below have also drifted from the implementation and are being corrected separately — trust the endpoint, not this schema, until that lands.
</Note>

- Only **enabled** agents are returned
- Use `agent_name` in [Stream a Chat](/api-reference/chat/stream) to route to a specific agent
- If no `agent_name` is provided, the default agent (or supervisor) handles the request
