## Overview

Check if the agent has a valid LLM configuration before starting a chat. iOS clients should call this on app launch to show appropriate UI when no LLM is configured.

## Response

<ResponseField name="is_ready" type="boolean">
  Whether the agent is ready for chat.
</ResponseField>

<ResponseField name="llm_configured" type="boolean">
  Whether an LLM provider has been configured in the dashboard.
</ResponseField>

<ResponseField name="llm_provider" type="string">
  The configured LLM provider (e.g., `"openai"`, `"anthropic"`, `"groq"`).
</ResponseField>

<ResponseField name="llm_model" type="string">
  The configured model name (e.g., `"gpt-4o"`, `"claude-sonnet-4-20250514"`).
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable status message.
</ResponseField>

<ResponseField name="capabilities" type="array">
  What the agent can do right now, so a client offers a feature only where it will work. Each entry is `{ "key": string, "enabled": boolean }`; keys are `image`, `video`, `web`, `skills` and `voice`. Empty whenever `is_ready` is false. `voice` is on when the developer enabled [voice input](/dashboard/voice) — the signal to show a microphone; [`/v1/voice/config`](/api-reference/voice/config) then carries the defaults.
</ResponseField>

<ResponseExample>
```json Ready
{
  "is_ready": true,
  "llm_configured": true,
  "llm_provider": "openai",
  "llm_model": "gpt-4o",
  "message": "Agent is ready for chat.",
  "capabilities": [
    { "key": "image", "enabled": false },
    { "key": "skills", "enabled": true },
    { "key": "video", "enabled": false },
    { "key": "voice", "enabled": true },
    { "key": "web", "enabled": true }
  ]
}
```

```json Not Configured
{
  "is_ready": false,
  "llm_configured": false,
  "llm_provider": null,
  "llm_model": null,
  "message": "No LLM configured. Please configure an LLM provider in the dashboard.",
  "capabilities": []
}
```
</ResponseExample>

## Example

<CodeGroup>
```swift Swift
let status = try await client.getAgentStatus()

if !status.isReady {
    // Show setup required UI
    showConfigurationRequired()
}
```

```bash cURL
curl https://api.astralform.ai/v1/agent/status \
  -H "Authorization: Bearer sk_xxxxxxxxxxxx"
```
</CodeGroup>
