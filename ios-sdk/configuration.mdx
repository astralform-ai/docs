## Basic Configuration

`ChatSession` is the app-facing entry point; `AuthMode` decides who it speaks as.

```swift
import Astralform

let session = ChatSession(
    authMode: .apiKey(
        AstralformApiKeyConfig(apiKey: "sk_xxxxxxxxxxxx", userId: "user-42")
    )
)
```

Use `.apiKey` when your own backend holds the key and you supply the end user's id. For an end user signed in through OAuth, pass their token instead:

```swift
let session = ChatSession(
    authMode: .userToken(
        AstralformUserTokenConfig(accessToken: accessToken, agentId: agentId)
    )
)
```

## Configuration Options

### Custom Base URL

For self-hosted deployments:

```swift
let session = ChatSession(
    authMode: .apiKey(
        AstralformApiKeyConfig(
            apiKey: "sk_xxxxxxxxxxxx",
            userId: "user-42",
            base: AstralformBaseConfig(baseURL: URL(string: "https://your-server.com")!)
        )
    )
)
```

### Request Timeout

`timeoutMs` covers REST calls only — it does not apply to uploads or to the SSE stream. Default is 30,000.

```swift
let session = ChatSession(
    authMode: .apiKey(
        AstralformApiKeyConfig(
            apiKey: "sk_xxxxxxxxxxxx",
            userId: "user-42",
            base: AstralformBaseConfig(timeoutMs: 60_000)
        )
    )
)
```

## Secure API Key Storage

<Warning>
  Never hardcode API keys in your source code or commit them to version control.
</Warning>

### Using Keychain

```swift
import Security

func storeAPIKey(_ key: String) {
    let data = key.data(using: .utf8)!
    let query: [String: Any] = [
        kSecClass as String: kSecClassGenericPassword,
        kSecAttrService as String: "com.yourapp.astralform",
        kSecAttrAccount as String: "api-key",
        kSecValueData as String: data
    ]
    SecItemAdd(query as CFDictionary, nil)
}

func retrieveAPIKey() -> String? {
    let query: [String: Any] = [
        kSecClass as String: kSecClassGenericPassword,
        kSecAttrService as String: "com.yourapp.astralform",
        kSecAttrAccount as String: "api-key",
        kSecReturnData as String: true
    ]
    var result: AnyObject?
    SecItemCopyMatching(query as CFDictionary, &result)
    guard let data = result as? Data else { return nil }
    return String(data: data, encoding: .utf8)
}
```

### Using Environment Variables (Debug)

For development, use Xcode's scheme environment variables:

1. Edit your scheme (**Product > Scheme > Edit Scheme**)
2. Go to **Run > Arguments > Environment Variables**
3. Add `ASTRALFORM_API_KEY` with your key

```swift
let apiKey = ProcessInfo.processInfo.environment["ASTRALFORM_API_KEY"] ?? ""
```
