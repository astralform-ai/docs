## Requirements

- iOS 18.0+ or macOS 15.0+
- Xcode 16.3+
- Swift 6.1+

## Swift Package Manager

Add Astralform to your Xcode project:

1. Open your project in Xcode
2. Go to **File > Add Package Dependencies**
3. Enter the repository URL:
   ```
   https://github.com/astralform-ai/Astralform-iOS-SDK
   ```
4. Select **Up to Next Minor Version** with `0.1.0`
5. Click **Add Package**

Or add it to your `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/astralform-ai/Astralform-iOS-SDK", .upToNextMinor(from: "0.1.0"))
]
```

Then add the dependency to your target:

```swift
.target(
    name: "YourApp",
    dependencies: [.product(name: "Astralform", package: "Astralform-iOS-SDK")]
)
```

<Note>
  The SDK is pre-1.0, so a breaking change bumps the minor version (0.1 to 0.2). Pin to the next minor version: a plain `from: "0.1.0"` would also accept a breaking 0.2.0.
</Note>

## Import the SDK

```swift
import Astralform
```
