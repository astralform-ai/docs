## Overview

Many services publish a hosted [Model Context Protocol](https://modelcontextprotocol.io) server — Sentry, Linear, Notion, GitHub, Stripe and others. Astralform connects to them as **remote MCP connectors**: a catalog entry names the server, each member authorizes their own account through the server's OAuth, and the agent gets the tools the server lists.

This is the same way Claude, Codex and Cursor connect to those services. Nothing runs inside Astralform for the integration, and nothing is pasted: the server's own authorization server issues the grant.

## How a connection works

1. An admin enables the connector for a project. No credentials are entered.
2. A member clicks **Connect** on the connector page. Astralform discovers the server's authorization server (per the MCP authorization spec), registers itself with it once, and opens the consent screen in a popup.
3. The member approves. The grant is stored encrypted, per member, and refreshed automatically.
4. On the member's next conversation the agent's tools are **discovered from the server**, cached for an hour, and listed on the connector page.

Tools carry the connector's slug as a prefix (`sentry_search_issues`), so the connector's [access policy](/dashboard/connectors#access-policy) governs all of them, and the write tools follow the agent's [Autonomy](/dashboard/permissions) setting.

## Available servers

| Connector | Server | Guide |
|-----------|--------|-------|
| Sentry | `https://mcp.sentry.dev/mcp` | [Sentry](/dashboard/sentry) |

Servers are added to the catalog by Astralform. To request one, open an issue with the server's URL; a server has to speak streamable HTTP and the MCP authorization spec (protected-resource metadata, dynamic client registration, PKCE).

## Limits

- Grants are per member. Routines and goals run under no member, so they have no connection until a member lends theirs (a follow-up).
- Only the server's **tools** are used; resources, prompts and sampling are not.
- Self-hosted MCP servers and developer-supplied URLs are not supported yet.
