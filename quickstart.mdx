## Prerequisites

- Xcode 16.3+
- iOS 18+ deployment target
- An Astralform account at [astralform.ai](https://astralform.ai)

## Step 1: Create an Agent

1. Go to [astralform.ai](https://astralform.ai) and sign in
2. Open the agent switcher at the top of the sidebar → **New agent**, enter a name, and create it. Save the encryption key it shows you.
3. Go to **Settings** → **API Keys**, create a key, and copy it — it's shown only once.

## Step 2: Install the SDK

Add Astralform to your Xcode project using Swift Package Manager:

1. In Xcode, go to **File > Add Package Dependencies**
2. Enter the repository URL:
   ```
   https://github.com/astralform-ai/Astralform-iOS-SDK
   ```
3. Select **Up to Next Minor Version** with `0.1.0` and click **Add Package**. [Installation](/ios-sdk/installation) explains why the pin stops at the next minor version.

## Step 3: Configure the Client

`ChatSession` is the app-facing entry point: it owns the connection, the conversation list, the message history and your client tools.

```swift
import Astralform

let session = ChatSession(
    authMode: .apiKey(
        AstralformApiKeyConfig(apiKey: "sk_xxxxxxxxxxxx", userId: "user-42")
    )
)
try await session.connect()
```

`userId` identifies the end user this session speaks for; each one gets its own conversations and memory.

<Warning>
  Never hardcode API keys in production. Use environment variables or secure storage.
</Warning>

## Step 4: Connect a Model Provider

Your agent runs on a model from a provider you connect with your own key. In the dashboard, open the account menu at the bottom of the sidebar → **Model providers**, and connect a provider with its API key.

An agent has no default model. Each conversation names its model on its first message, from the providers your team connected: `GET /v1/models` lists them. See [Model Providers](/dashboard/llm-providers) for the supported providers.

## Step 5: Send Your First Message

Subscribe first, then send — the response arrives as events on the session, not as a return value. `send` creates a conversation for you when there isn't one yet.

```swift
let subscription = session.on { event in
    switch event {
    case .blockDelta(_, .text(let text)):
        print(text, terminator: "")
    case .messageStop:
        print("\n[Done]")
    case .error(let code, let message, _):
        print("Error \(code): \(message)")
    default:
        break
    }
}

try await session.send(
    "Hello! What can you help me with?",
    options: SendOptions(provider: "anthropic", model: "claude-sonnet-5")
)
session.unsubscribe(subscription)
```

Name a provider you connected and one of its models. A conversation's first message must name its model; later messages can leave `provider` and `model` out and reuse it.

`send` returns once the turn is complete — it consumes the job's event stream before returning — so it is safe to unsubscribe on the next line. A `default` case is required: the session emits the whole [block protocol](/api-reference/chat/stream#the-block-protocol) plus conversation-level events, and more can be added without breaking your build.
